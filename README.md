# Lista de Compras - Aplicação Simples

Este é um código simples em Python que permite ao usuário gerenciar uma lista de compras. O programa oferece funcionalidades básicas de adicionar, remover e visualizar os itens na lista de compras.

## Funcionalidades

- **Adicionar Produto:** O usuário pode adicionar itens à lista de compras.
- **Remover Produto:** O usuário pode remover um item da lista fornecendo o índice.
- **Ver Lista de Compras:** O usuário pode visualizar todos os itens presentes na lista de compras.

## Como Usar

1. Execute o código em um ambiente Python (como IDLE, Jupyter Notebook ou qualquer outro ambiente de sua preferência).
2. O programa solicitará que o usuário escolha uma das opções:
   - **[1] Adicionar**: Insira o produto que deseja adicionar à lista de compras.
   - **[2] Remover**: Informe o índice do item a ser removido.
   - **[3] Ver lista**: Mostra todos os produtos da lista de compras.

### Detalhes da Lista de Compras
- O índice dos produtos começa do número `0`, então o primeiro item da lista tem índice 0.
- Se a lista estiver vazia, uma mensagem será exibida para informar ao usuário.
